# 配布データガイド

このフォルダのファイルは、講義を通信環境に左右されず再現するためのスナップショットです。原データは上書きせず、加工結果を`data_clean/`へ保存してください。

## ファイル一覧

### `analysis_data.xlsx`

- `trade`: 2005年4月～2025年3月。表頭に「百万円」「季調値」の記載があります。
- `tx_data`: 1行1掲載物件。`monthly_rent`、`size_sqm`、`building_age`、`minutes_to_station`、`tx_indicator`等を含みます。
- `pharma_finance`: 企業×年度の財務変数。
- `pharma_patent`: 1行1特許記録として集計する想定。
- `bop`: 過去講義用の月次データ。
- `watcher_text`: 地域別の指数とコメント。

`tx_data`の各数値の単位、`tx_indicator`の厳密な定義、製薬財務列の略称（`TA`、`ITA`、`A`、`E`、`R`）は、添付ファイルだけでは完全には確認できません。授業で分析解釈に使う場合は、元の作成資料または定義表を追加してください。

### `a_bop.csv`

- 文字コード: UTF-8
- 期間: 1996年1月～2025年3月
- `year`は各年の1月だけに入り、以降の月は空欄です。
- `trade_balance`は演習用に空欄です。
- 出所表記: 財務省・日本銀行『国際収支統計』

金額単位はCSV内に明記されていないため、報告用資料では元統計または配布時の定義表を確認してください。

### `a_usdjpy.csv`

- 文字コード: UTF-8
- 期間: 1996年1月～2025年3月
- `year`は各年の1月だけに入り、以降の月は空欄です。

`usd_jpy`の厳密な定義・単位はファイル内にありません。為替水準として解釈する前に元資料を確認してください。

### `b_weo.xlsx`

- `weo`: IMF World Economic Outlook Database, April 2025
- `group_map`: G7、EU（G7加盟国除く）、ASEANの対応表
- 各系列の`units`、`scale`、`estimates_start_after`を分析時に確認してください。
- 2030年は予測端点です。

### `c_pref_gdp.xlsx`

- `gdp`: 都道府県×年の横持ちデータ
- `compensation`: 都道府県×年の横持ちデータ
- `agri_forestry`: 都道府県×2021年の縦持ちデータ
- 出所表記: 内閣府 令和3年度『県民経済計算』

配布ファイルの単位・名目実質区分は元資料で確認し、図表の注記へ残してください。

### `estat/`

第2章のAPI実習で、取得時点のレスポンスJSON/RDSを保存する場所です。取得条件、コード表、整形済みデータ、ログは`data_clean/`にも保存されます。
