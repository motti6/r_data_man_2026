第5章 ggplot2による実データ可視化

分布、関係、推移、ランキングを伝える

Noteこの章の到達目標
  1. 分析目的と変数の型に応じて、適切なグラフを選べる。
  2. ggplot()、aes()、geom_*()の役割を説明できる。
  3. 賃貸物件、貿易、国際収支、WEO、都道府県GDPを可視化できる。
  4. 軸、単位、凡例、注記、出所を整え、第三者に伝わる図を作れる。
  5. 異なる単位の系列を、安易な二軸グラフではなく、指数化やファセットで比較できる。
  6. 図をオブジェクトとして保存し、再現可能な形式で出力できる。

1 グラフを描く前に決めること

  1. 何を伝えるか：分布、比較、関係、推移のどれか。
  2. 観測単位は何か：物件、国、都道府県、月など。
  3. 変数の型は何か：連続値、カテゴリ、日付など。
  4. 単位と対象期間は何か。
  5. 探索用か、報告用か。
確認したいこと 代表的なグラフ
カテゴリの件数 棒グラフ
連続値の分布 ヒストグラム、密度図
群ごとの分布 箱ひげ図、バイオリン図
2変数の関係 散布図
時系列の推移 折れ線、棒グラフ
複数群・複数系列 色、線種、ファセット
Importantグラフは因果関係を自動的に示さない

散布図に右上がりの傾向があっても、他の変数、逆方向の因果、データの選択によって生じた可能性があります。グラフは、データの特徴を発見し、仮説や分析結果を伝える道具です。

2 ggplot2の基本構造

ggplot(
  data = tx_df,
  mapping = aes(x = size_sqm, y = monthly_rent)
) +
  geom_point()
  • ggplot(data, aes(...))：データと変数の対応を決める。
  • geom_*()：点、線、棒、箱などの形を加える。
  • scale_*()：軸、色、目盛り、ラベル形式を調整する。
  • labs()：タイトル、軸名、凡例、注記を加える。
  • facet_*()：小さな複数図へ分割する。
  • theme_*()：背景、文字、凡例位置などを整える。

+は前の行の末尾に置きます。

3 カテゴリの件数：棒グラフ

間取り別の物件数を確認します。

tx_df |>
  count(layout, name = "n") |>
  mutate(layout = fct_reorder(layout, n)) |>
  ggplot(aes(x = layout, y = n)) +
  geom_col() +
  coord_flip() +
  labs(
    x = "間取り",
    y = "物件数",
    caption = "資料：過去講義用の賃貸物件データ"
  ) +
  theme_minimal(base_family = "sans")

geom_bar()は行数を内部で数えます。集計済みの値を棒の高さにするときはgeom_col()を使います。

上位の間取りだけを示す場合は、除外条件を注記します。

layout_top10 <- tx_df |>

ggplot(layout_top10, aes(x = layout, y = n)) +

    x = NULL,

bind_rows(

coord_cartesian()は表示範囲を変えるだけで、回帰線の推計に使う観測を削除しません。分析対象を限定したい場合はfilter()を使い、その理由を明示します。

9 異なる単位を比較する：指数化

輸出額、輸入額、経常収支は水準も符号も異なるため、経常収支を含む単純指数化は注意が必要です。ここでは正の値である輸出と輸入を、2019年平均=100へ指数化します。

trade_index <- trade_long |>
  group_by(series) |>
  mutate(
    base_2019 = mean(value[year(date) == 2019], na.rm = TRUE),
    index_2019 = value / base_2019 * 100
  ) |>
  ungroup()
ggplot(trade_index, aes(x = date, y = index_2019, linetype = series)) +
  geom_hline(yintercept = 100) +
  geom_line(linewidth = 0.7) +
  labs(
    x = NULL,
    y = "2019年平均=100",
    linetype = NULL,
    caption = "資料：過去講義用の貿易統計スナップショット"
  ) +
  theme_minimal(base_family = "sans") +
  theme(legend.position = "bottom")

二軸グラフは、軸の取り方で関係が強く見えたり弱く見えたりします。指数化、前年差、標準化、ファセットを優先します。

11 第2章のAPIデータを使う

第2章のAPI実習でdata_clean/pref_population_2020.csvを作成した場合、2020年の一人当たりGDPを計算できます。APIをまだ実行していない場合も、この章の他の図は配布スナップショットだけで再現できます。

has_api_population <- file.exists("data_clean/pref_population_2020.csv")
has_api_population

12 WEOで国際比較を描く

WEOは、1行が1国・1指標、年が横方向に並ぶ形式です。必要な系列を縦長へ変換します。

weo_raw <- read_excel(
  file.path("data_raw", "b_weo.xlsx"),
  sheet = "weo",
  col_types = "text",
  na = c("", "--", "...", "n/a")
)

year_columns <- names(weo_raw) |>
  str_subset("^\\d{4}$")

weo_long <- weo_raw |>
  pivot_longer(
    cols = all_of(year_columns),
    names_to = "year",
    values_to = "value_raw"
  ) |>
  mutate(
    year = parse_integer(year),
    value = parse_number(value_raw)
  )

group_map <- read_excel(
  file.path("data_raw", "b_weo.xlsx"),
  sheet = "group_map"
) |>
  select(iso3, group) |>
  distinct(iso3, .keep_all = TRUE)

2023年の購買力平価GDPと一人当たりGDPを国単位で横持ちへします。

weo_2023 <- weo_long |>
  filter(
    year == 2023,
    subject_code %in% c("PPPGDP", "PPPPC", "LP")
  ) |>
  select(iso, country, subject_code, value) |>
  pivot_wider(
    names_from = subject_code,
    values_from = value
  ) |>
  inner_join(
    group_map,
    by = join_by(iso == iso3),
    relationship = "many-to-one"
  )

地域GDPは国別GDPを合計できます。一人当たりGDPは単純合計せず、GDP合計を人口LPの合計で割ります。

weo_group_2023 <- weo_2023 |>
  summarise(
    countries = n(),
    ppp_gdp_billion = sum(PPPGDP, na.rm = TRUE),
    population_million = sum(LP, na.rm = TRUE),
    ppp_per_capita = ppp_gdp_billion / population_million * 1000,
    median_country_ppp_per_capita = median(PPPPC, na.rm = TRUE),
    .by = group
  )

13 ラベルと出所を整える

報告用の図には、少なくとも次を含めます。

  • 軸名と単位
  • 対象期間
  • 季節調整・名目実質などの定義
  • データ加工上の重要な条件
  • 出所

タイトルが長くなりすぎる場合は、本文で説明し、図には軸名と注記だけを置きます。

15.2 演習2：国際収支の図

2015年以降について、経常収支、貿易収支、サービス収支、第一次所得収支を四半期合計へ変換し、ファセットで表示してください。未完了四半期は除外します。

Tip解答例 
bop_quarter_plot <- bop |>
  filter(date >= as.Date("2015-01-01")) |>
  mutate(quarter = floor_date(date, "quarter")) |>
  summarise(
    current_account = sum(current_account, na.rm = TRUE),
    trade_balance = sum(trade_balance, na.rm = TRUE),
    services_balance = sum(services_balance, na.rm = TRUE),
    primary_income = sum(primary_income, na.rm = TRUE),
    months = n(),
    .by = quarter
  ) |>
  filter(months == 3) |>
  select(-months) |>
  pivot_longer(
    cols = -quarter,
    names_to = "component",
    values_to = "value"
  )

ggplot(bop_quarter_plot, aes(x = quarter, y = value)) +

15.3 演習3：2023年と2030年のWEO比較

G7、EU（G7加盟国除く）、ASEANについて、購買力平価GDPを2023年と2030年で比較する図を作ってください。2030年が予測値であることを注記します。

Tip解答例 
weo_group_compare <- weo_long |>
  filter(
    subject_code == "PPPGDP",
    year %in% c(2023, 2030)
  ) |>
  inner_join(
    group_map,
    by = join_by(iso == iso3),
    relationship = "many-to-one"
  ) |>
  summarise(
    ppp_gdp_billion = sum(value, na.rm = TRUE),
    .by = c(group, year)
  ) |>
  mutate(year = factor(year))

ggplot(
  weo_group_compare,
  aes(x = group, y = ppp_gdp_billion, fill = year)
) +
  geom_col(position = "dodge") +
  coord_flip() +
  labs(
    x = NULL,
    y = "購買力平価GDP（10億国際ドル）",
    fill = "年",
    caption = paste(
      "注：2030年はIMF予測。EUはG7加盟国を除く。",
      "資料：IMF WEO April 2025"
    )
  ) +
  theme_minimal(base_family = "sans")
