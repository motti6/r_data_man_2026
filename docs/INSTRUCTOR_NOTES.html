1 教員向けメモ

1.1 改訂方針

  • 架空の練習データは原則として使わず、過去講義の実データと追加配布データを使用しています。
  • 第2章でe-Stat APIの検索、メタデータ、試行取得、ページ分割、保存を扱います。
  • 講義の安定性はdata_raw/のスナップショットで確保し、更新能力はAPI演習で身につける二層構成です。
  • 第5章・第6章では、第2章で取得した人口を県民経済計算と結合します。
  • 追加のA～C演習は第6章へ統合し、解答例は折り畳み表示にしています。

1.2 追加演習の確認値

1.2.1 A 国際収支

  • 期間: 1996年1月～2025年3月
  • 行数: 351
  • trade_balance = exports - imports
  • 全期間の最小値: 2022年10月、-20330
  • 1月の最小値: 2023年、-16435
  • goods_services_balanceの再計算差は、丸め等により最大1程度残ります。

1.2.2 B WEO

2023年のPPPGDP合計（10億国際ドル）は、配布されたグループ対応表を使うと次のとおりです。

  • G7: 54338.781
  • EU（G7加盟国除く）: 13553.258
  • ASEAN: 11469.904

地域一人当たりGDPは、sum(PPPGDP) / sum(LP) * 1000で計算します。国別PPPPCを足し合わせないでください。

1.2.3 C 都道府県GDP

  • 2021年GDP上位: 東京都、愛知県、大阪府、神奈川県、埼玉県
  • 名称に「山」を含む: 山形県、富山県、山梨県、和歌山県、岡山県、山口県

「山」を含むという条件は文字列処理の課題であり、地形や中山間地域の分類ではありません。

1.3 授業前に確認したい未確定メタデータ

添付ファイルだけでは、次の定義を完全には確認できません。

  • TXデータの金額・距離等の単位とtx_indicatorの意味
  • 製薬財務列TA、ITA、A、E、Rの正式名称・単位
  • Aの国際収支データの金額単位
  • usd_jpyの正式な系列名、相場の向き、単位
  • 都道府県GDPファイルの単位と名目・実質区分

数値操作の演習には使えますが、経済的解釈を求める課題では元の定義表を追加するのが安全です。

1.4 e-Stat実習

  • 例示表: 人口推計、統計表表示ID 0003448237
  • 2020年の都道府県別総人口を47行に整形し、data_clean/pref_population_2020.csvへ保存します。

1.5 第7章・第8章（発展編）

1.5.1 学習の接続

  • 第2章：e-Stat人口APIの成果を都県プロフィールへ再利用
  • 第3章：キーを使う属性結合とrelationship検査
  • 第4章：複数ファイル・文字列・関数化
  • 第5章：地図以外の時系列・ランキング表示
  • 第6章：県内総生産、雇用者報酬、農林業シェア
  • 第7章：N03行政区域とS12駅別乗降客数を追加
  • 第8章：同じデータをリアクティブな意思決定画面へ統合

1.5.2 使用データ

  • N03行政区域：2026年1月1日時点、関東地方版
  • S12駅別乗降客数：2024年度、全国版
  • 県民経済計算：2011～2021年の配布スナップショット
  • 人口：第2章で取得した2020年人口（任意）

N03の東京都には離島が含まれるため、全域面積を保持したうえで、表示geometryのみ関東本土へ切り出します。この区別を明示的に説明してください。

S12は駅をlineとして持ち、同一駅が複数路線・事業者に現れます。教材ではstation_group単位にまとめ、乗降客数は最大値を採用します。合計値が必ず誤りという意味ではなく、重複計上を避けるための講義上の選択です。

1.5.5 重要な解釈上の注意

複数年次のデータを同じ画面へ載せるのは探索目的です。駅数・乗降客数とGDPの因果関係を示すものではありません。人口、都市化、産業構造、昼間人口、面積などの交絡を扱っていません。
