第1章 Rと再現可能なデータ分析の基礎

実データから始めるRデータ操作入門（2026年度版）

1 この章の到達目標

この章を終えると、次のことができるようになります。

  1. R、Positron/RStudio、Quartoの役割を区別する。
  2. プロジェクトと相対パスを使って、別のPCでも再現できる分析を作る。
  3. オブジェクト、型、ベクトル、データフレーム、欠損値を説明する。
  4. 配布されたExcelの実データを読み込み、構造と品質を確認する。
  5. AIが生成したコードを、実行前後に点検する観点を持つ。

2 AI時代にRを学ぶ理由

生成AIは、コードのたたき台を短時間で作れます。しかし、実務や研究で必要なのは「文字列としてのコード」ではなく、次の一連の判断です。

  • 何を一つの観測とするか。
  • 変数は何を測っているか。
  • 欠損値や外れ値をどう扱うか。
  • 集計や結合で行数が不自然に増えていないか。
  • 結果が元データと定義から説明できるか。

Rを学ぶ目的は、すべての関数を暗記することではありません。処理を読める、疑える、修正できる、再実行できる状態を作ることです。

Tip授業でのAIの使い方

AIには「答えだけ」ではなく、次を伝えて質問します。

  • データの列名と型
  • 目的と期待する完成形
  • 使ってよいパッケージ
  • エラー全文
  • 自分が確認したこと

生成されたコードは、一行ずつ意味を説明できる範囲で使います。

5 プロジェクトと相対パス

教材は次の構造を前提とします。

r_data_course_2026/
├─ chapter1_2026.qmd
├─ chapter2_2026.qmd
├─ ...
├─ data_raw/       # 入手したままの原データ
├─ data_clean/     # コードで整形したデータ
├─ output_data/    # 表などの出力
├─ figures/        # 図の出力
└─ R/              # 再利用する関数

プロジェクトを開いたとき、次の相対パスは誰のPCでも同じ意味になります。

analysis_path <- file.path("data_raw", "analysis_data.xlsx")

次のような絶対パスは、別の利用者や別のPCでは通常動きません。

# 推奨しない例
analysis_path <- "C:/Users/user_id/Desktop/analysis_data.xlsx"
Warningsetwd()で無理に合わせない

作業ディレクトリをコード内で個人のフォルダへ変更すると、他の人の環境で再現できません。プロジェクトを正しく開き、相対パスを使います。

10 条件式

比較演算子は、データを抽出するときの基礎になります。

演算子 意味
== 等しい
!= 等しくない
>、>= より大きい、以上
<、<= より小さい、以下
%in% 候補のいずれかに含まれる
& 両方を満たす
| どちらかを満たす
! 否定 
(tx$monthly_rent >= 10) |>
  head()
[1] FALSE  TRUE FALSE FALSE FALSE  TRUE
sum(tx$size_sqm >= 50, na.rm = TRUE)
[1] 649
sum(
  tx$layout %in% c("1LDK", "2LDK") & tx$minutes_to_station <= 10,
  na.rm = TRUE
)
[1] 326
Warning=と==を区別する
  • x <- 3 または関数内の na.rm = TRUE は設定・代入。
  • x == 3 は「等しいか」という比較。

12 欠損値 NA

欠損値は「0」ではなく、「観測されていない、利用できない、該当しない」などを表します。

mean(c(5, 7, NA))
[1] NA
mean(c(5, 7, NA), na.rm = TRUE)
[1] 6

na.rm = TRUE は欠損を除いて計算する指定ですが、常に正しいとは限りません。欠損が特定の地域、企業、期間に偏っていれば、除外後の平均は母集団を代表しなくなります。

TXシートでは欠損数を次のように確認できます。

tibble(
  variable = names(tx),
  missing_n = colSums(is.na(tx)),
  missing_rate = colMeans(is.na(tx))
)

13 関数を作る

同じ処理を繰り返すときは、関数にします。

safe_mean <- function(x) {
  if (all(is.na(x))) return(NA_real_)
  mean(x, na.rm = TRUE)
}

safe_mean(tx$monthly_rent)
[1] 8.442016

関数名は、処理の目的が分かる名前にします。

14 エラーとヘルプ

関数の使い方を確認するには、次を使います。

?mean
help("mean")
example(mean)

エラーが出たら、まず次を確認します。

  1. ファイルパスが正しいか。
  2. 列名の大文字・小文字や全角・半角が一致しているか。
  3. パッケージを読み込んだか。
  4. 括弧、引用符、カンマが閉じているか。
  5. オブジェクトを作るコードを先に実行したか。

15 AIが作ったコードを点検する5問

  1. 入力ファイルとシート名は実在するか。
  2. 使用している列名はデータに存在するか。
  3. 欠損値をどう扱っているか。
  4. 行数は処理前後で想定どおりか。
  5. 出力値を元データの数行から手計算で確かめられるか。

16 演習

16.1 問1

16.2 問2

monthly_rent、size_sqm、minutes_to_station の平均・中央値・最小値・最大値を求めてください。欠損数も併記してください。

次の条件を満たす物件数を求めてください。

  • minutes_to_station が10以下

16.4 問4
